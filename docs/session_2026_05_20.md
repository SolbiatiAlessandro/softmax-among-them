## Correct Workflow: coworld (NOT cogames)

The previous session used `cogames`, which has a Python policy format but only
Cogs vs Clips seasons. The CORRECT public tournament uses `coworld`:

### coworld vs cogames
| | cogames | coworld |
|---|---|---|
| Policy format | Python | Nim/Docker |
| Token format | Bearer | X-Auth-Token |
| Among Them season | NOT available | Via leagues API (auth needed) |
| CLI | `cogames submit` | `coworld certify` |

### Full Submission Workflow (when auth works)

```bash
# 0. Set up (once per environment)
uv add "coworld[auth]"
uv run softmax set-token '<TOKEN>'

# 1. Discover the Among Them Daily league
uv run coworld leagues
# Find league ID like: league_...

# 2. Find the division
uv run coworld divisions --league <LEAGUE_ID>
# Find division ID like: div_...

# 3. Download the Among Them coworld package
uv run coworld download among_them
# This creates: ./coworld/<coworld-id>/coworld_manifest.json
# Remember the coworld-id printed

# 4. Test locally (requires Docker, which needs internet for Alpine packages)
uv run coworld run-episode ./coworld/<coworld-id>/coworld_manifest.json \
  lessandro-nirvana:latest --timeout-seconds 120

# 5. Build Docker image (BLOCKED in sandbox - TLS issues with Alpine repos)
docker build --platform=linux/amd64 -t lessandro-nirvana:latest ./lessandro_nirvana/

# 6. Certify and submit
uv run coworld certify --league <LEAGUE_ID> --division <DIV_ID> \
  --image lessandro-nirvana:latest --name lessandro-nirvana

# OR use the one-liner:
uv run coworld upload-policy --image lessandro-nirvana:latest
uv run coworld submit --league <LEAGUE_ID>
```

## Scoring Hypothesis

Based on Among Us game theory:
- **Crewmate score** ∝ tasks completed / total tasks × time efficiency
- **Imposter score** ∝ crewmates killed before detection
- **Team score**: all crewmates finish tasks → crewmate team wins; imposters
  kill majority → imposter team wins

Improvement strategy for highest score:
1. As crewmate: complete all 8 tasks as fast as possible (task ordering matters)
2. As imposter: kill early before crew is alert, vote innocuously
3. Social: read chat for sus patterns, use "X sus" strategically
