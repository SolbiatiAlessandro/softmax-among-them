## Game: Among Them — Sprite Player Protocol

The Among Them game passes each agent a **1231-dimensional flat observation**:

| Range         | Content                                   |
|---------------|-------------------------------------------|
| obs[0]        | Phase: LOBBY=0 PLAYING=1 VOTING=2 RESULT=3 OVER=4 ROLE=5 |
| obs[1]        | Kill icon: 0=crewmate/cooldown 1=cooldown 255=ready-to-kill |
| obs[2]        | Task progress byte (0-255)                |
| obs[3]        | Tasks remaining counter                   |
| obs[4:1028]   | 32×32 map grid (PICO-8 color indices)    |
| obs[1028:1092]| 16 players × 4: [x, y, color, flags]     |
| obs[1092:1156]| 16 bodies × 4: [x, y, color, present]   |
| obs[1156:1231]| 15 tasks × 5: [icon_x, icon_y, arrow_x, arrow_y, flags] |

Player flags: `present=1, alive=4, flip_h=16, ghost=32`  
Task flags: `icon_visible=1, arrow_visible=2`

The camera always centers on the observing player at screen position (64, 64).
Task screen coordinates are relative to this center.

## Policy: lessandro-nirvana (files in this repo)

**File**: `lessandro_nirvana_policy.py`
**Docker**: `lessandro_nirvana/` directory

### Strategy
1. **Phase detection**: read `obs[0]` to pick behaviour
2. **During PLAYING**:
   a. Find nearest task icon (obs[1156+t*5] flags & 1) → navigate there + press A
   b. If no icon, follow task arrow (flags & 2) → navigate toward arrow
   c. If imposter (obs[1]==255) and no tasks visible → find nearest alive player, press A to kill
   d. If nothing visible → systematic exploration pattern (staggered by slot to spread out)
3. **During VOTING**: press A every 25 ticks (votes for someone)
4. **During LOBBY/ROLE**: press A to advance
5. **Pixel mode fallback**: color-based navigation (same as dharma, improved thresholds)

### Key improvements over lessandro-dharma
- Uses sprite_player observations (1231-dim) instead of pixel frame analysis
- Knows game phase (doesn't waste time pressing buttons during voting UI)
- Detects imposter role via kill_icon flag — switches to kill strategy
- Navigates diagonally for more efficient movement
- Agents are staggered (slot × prime) so they spread across the map
- Task arrow following guides to off-screen tasks

### Imposter role detection
`obs[1] > 0` means imposter:
- `obs[1] == 1` → imposter, kill on cooldown → do tasks to avoid suspicion
- `obs[1] == 255` → imposter, kill ready → hunt nearest alive player

## Docker Player Protocol

The `lessandro_nirvana/player.py` connects to `$COGAMES_ENGINE_WS_URL`.

**Pixel mode** (`/player` path):
- Receive: 8192-byte packed PICO-8 frames (128×128, 4-bit packed)
- Send: `bytes([0x00, button_mask])`
- Unpack: `frame[0::2] = packed & 0x0F; frame[1::2] = packed >> 4`

**Sprite-player mode** (`/sprite_player` path):
- Receive: binary structured sprite updates
- Process: `SpritePlayerObservationAdapter.apply_packet(data)`
- Get obs: `adapter.observation()` → shape (1231,)
- Send: `bytes([0x84, button_mask])`

The slot number is extracted from the URL query string: `?slot=N&token=T`.
