## Bitworld Codebase (from GitHub)

The game source is at `https://github.com/Metta-AI/bitworld.git`.

### Protocol (BitScreen v1)

- WebSocket at `COGAMES_ENGINE_WS_URL`
- **Frame**: 8192 bytes binary, 128×128 pixels, 4-bit PICO-8 palette, packed 2 px/byte
- **Button packet**: 2 bytes: `[0x00, button_mask]` where mask bits:
  - bit 0: up, bit 1: down, bit 2: left, bit 3: right
  - bit 4: select (report/vote), bit 5: A (interact), bit 6: B
- **Chat packet**: `[0x01, ...ASCII...]`

## lessandro-nirvana Policy

### Architecture

Based on `italkalot.nim` (the best available Nim bot with LLM integration).
Changed the AI backend from OpenAI (`bitworld/ais/openai`) to OpenRouter
(`bitworld/ais/openrouter` — our custom module).

**Visual pipeline** (inherited from italkalot, unchanged):
1. Patch-hash-based camera localization on the Skeld map
2. A* pathfinding on walk mask with momentum-aware movement
3. Task detection via icon matching + task state machine
4. Body/ghost detection and reporting
5. Voting screen parsing (slots, cursor, chat OCR, votes)

**LLM layer** (changed to OpenRouter):
- Two async chat turns during voting interstitial
- LLM vote decision after reading voting screen context
- Reads `OPENROUTER_API_KEY` env var; falls back to deterministic if unset
- Default model: `anthropic/claude-haiku-4-5` (fast, cheap)
- Configurable via `OPENROUTER_MODEL` env var

### Files created

```
softmax-among-them/lessandro_nirvana/
├── lessandro_nirvana.nim       # italkalot.nim with openrouter import
├── openrouter.nim              # OpenRouter Chat Completions API module
├── lessandro_nirvana_binary    # pre-compiled x86_64 Linux binary
├── nimby.lock                  # Nim package lock file
├── Dockerfile                  # pre-compiled binary Docker packaging
└── (build artifacts)
```

### Compilation

The binary was compiled on the host (not inside Docker) due to TLS cert issues
in the sandbox Docker environment that prevent package downloads.

```bash
# On any Linux/amd64 host with Nim 2.2.4:
export PATH="/root/.nimby/nim/bin:$PATH"
cd bitworld/among_them/players/lessandro_nirvana
nim c -d:release -d:botHeadless --out:lessandro_nirvana lessandro_nirvana.nim
```

Required: nimby packages from `bitworld/nimby.lock`.

### Docker build (pre-compiled approach)

The Dockerfile packages the pre-compiled binary:
```bash
# Build context: must have among_them/ and clients/data/ from bitworld repo
docker build --platform=linux/amd64 -t lessandro-nirvana:latest .
```

Dependency: `libcurl4` (installed via apt in the Dockerfile).

### Submission (when auth is fixed)

```bash
# Step 1: Get league ID
uv run coworld leagues  # look for Among Them Daily → league_...

# Step 2: Upload policy with OpenRouter API key
uv run coworld upload-policy lessandro-nirvana:latest \
  --name "lessandro-nirvana" \
  --secret-env "OPENROUTER_API_KEY=<YOUR_OPENROUTER_API_KEY>" \
  --secret-env "OPENROUTER_MODEL=anthropic/claude-haiku-4-5"

# Step 3: Submit
uv run coworld submit "lessandro-nirvana" --league <league_id>

# Step 4: Monitor
uv run coworld submissions --mine --league <league_id>
uv run coworld episodes --mine --with-replay
```

## Docker TLS Issue in Sandbox

The Docker daemon in this sandbox has TLS certificate issues: HTTPS downloads
inside Docker containers fail with "self-signed certificate in certificate chain".

**Workaround used**: Compile the Nim binary on the host (which has proper TLS),
then package the pre-compiled binary in a simple Debian-based Docker image.

**Production Dockerfile** (works outside sandbox): The `lessandro_nirvana/`
directory contains a source-based Dockerfile that clones bitworld and compiles
from source. This is what should be used in production where TLS works.

**Commands to build from source** (for production/Softmax infra):
```bash
docker build --platform=linux/amd64 -t lessandro-nirvana:latest \
  -f Dockerfile.from_source .
```

## Strategy Analysis

### Score factors in Among Them

The scoring (from `coworld_manifest.json`) rewards:
- **Crew win**: complete all tasks before imposters kill everyone
- **Imposter win**: kill crew down to equal number (or task bar fails)

### Where the LLM helps

1. **Voting accuracy**: Correctly vote out imposters instead of innocents
2. **Chat evidence sharing**: "I saw Red leave body in MedBay at t=142"
3. **Imposter deception**: False alibis, blame redirection
4. **Meeting timing**: Call vote when kill is witnessed

### Improvement ideas for next session

1. **Better voting prompt**: Include room-movement history, not just chat text
2. **Imposter coordination** (not yet implemented): communicate via chat with
   imposter partner
3. **Adaptive suspicion thresholds**: Lower threshold near end-game
4. **LLM-powered alibi generation**: Proactively claim tasks as imposter
5. **Vision-based strategy**: Use pixel analysis of task bar (crew progress)

## Environment Setup (from scratch)

```bash
# 1. Install coworld CLI
mkdir project && cd project
uv init --bare --name project
uv add "coworld[auth]"

# 2. Auth (requires fresh browser token)
uv run softmax set-token '<TOKEN>'
uv run softmax status  # verify: subject_type: user

# 3. Check leagues
uv run coworld leagues  # find league_... for Among Them Daily

# 4. Install Nim for recompilation
curl -fsSL https://github.com/treeform/nimby/releases/download/0.1.26/nimby-Linux-X64 \
  -o /usr/local/bin/nimby && chmod +x /usr/local/bin/nimby
nimby use 2.2.4
export PATH="$HOME/.nimby/nim/bin:$PATH"

# 5. Install bitworld deps
git clone https://github.com/Metta-AI/bitworld.git
cd bitworld && nimby --global sync nimby.lock
cat nim.cfg >> ~/.nimby/nim/config/nim.cfg

# 6. Copy lessandro_nirvana files and compile
cp softmax-among-them/lessandro_nirvana/openrouter.nim src/bitworld/ais/
mkdir -p among_them/players/lessandro_nirvana
cp softmax-among-them/lessandro_nirvana/lessandro_nirvana.nim \
  among_them/players/lessandro_nirvana/
cd among_them/players/lessandro_nirvana
nim c -d:release -d:botHeadless --out:lessandro_nirvana lessandro_nirvana.nim
```
