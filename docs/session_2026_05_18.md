## Game Knowledge: Among Them Protocol

### Observation Modes

**Pixel mode**: `(batch, 4, 128, 128)` uint8, PICO-8 colour indices 0–15.
Already documented in session_2026_05_12.md.

**Sprite_player mode**: `(batch, SPRITE_PLAYER_FEATURES)` = `(batch, 1231)` uint8.

Feature layout:
```
obs[0]      phase:   0=lobby 1=playing 2=voting 3=vote_result 4=game_over 5=role_reveal
obs[1]      kill_icon: 0=crewmate, 1=imposter_cooldown, 255=kill_ready
obs[2]      task_progress_bar (0–255, scaled from %)
obs[3]      tasks_remaining_count
obs[4:1028] 32×32 map grid (PICO-8 colour per cell, 4px resolution)
obs[1028:1092] 16 players × 4 features: [x, y, color, flags]
             flags: bit0=present, bit2=alive, bit4=flip_h, bit5=ghost
obs[1092:1156] 16 bodies × 4 features: [x, y, color, present_flag]
obs[1156:1231] 15 tasks × 5 features: [bubble_x, bubble_y, arrow_x, arrow_y, flags]
             flags: bit0=task_icon_visible, bit1=task_arrow_visible
```

Player position coordinates are in screen space (0–127 for the 128px screen).
Screen centre is (64, 64). The camera follows the local player, so the local
player is always near screen centre.

### Action Space (trainable only)

27 actions. SELECT is NOT in the trainable set.

```
noop    a    b
up      up+a    up+b
down    down+a  down+b
left    left+a  left+b
right   right+a right+b
up+left    up+left+a    up+left+b
up+right   up+right+a   up+right+b
down+left  down+left+a  down+left+b
down+right down+right+a down+right+b
```

Action indices: noop=0, a=1, b=2, up=3, down=6, left=9, right=12, ...

### Key Game Constants

```python
BITWORLD_AMONG_THEM_PLAYER_COUNT    = 8
BITWORLD_AMONG_THEM_IMPOSTER_COUNT  = 2
BITWORLD_AMONG_THEM_TASKS_PER_PLAYER = 8
BITWORLD_AMONG_THEM_IMPOSTER_COOLDOWN_TICKS = 1200
BITWORLD_AMONG_THEM_VOTE_TIMER_TICKS = 6000
AMONG_THEM_MAX_PLAYERS = 16 (max supported, game uses 8)
SPRITE_PLAYER_TASK_COUNT = 15 (max visible tasks in obs)
```

### Imposter Detection via Observation

The `kill_icon` at `obs[1]` tells us our role:
- 0 → crewmate (no kill icon shown)
- 1 → imposter, kill on cooldown
- 255 → imposter, kill ready to use

This is extremely useful: we can adapt strategy based on our role without
needing external labelling.

## Policy: lessandro-nirvana

### Improvements over lessandro-dharma

| Feature | dharma | nirvana |
|---------|--------|---------|
| Observation mode | pixel only | sprite_player + pixel fallback |
| Task detection | colour heuristic | exact task bubble/arrow positions |
| Role awareness | none | reads kill_icon to detect imposter |
| Imposter strategy | none | navigate to nearest player, kill when ready |
| Navigation | quadrant scoring | direct screen-coord navigation |
| Voting | periodic SELECT (invalid!) | A-press every 45 ticks |

**Critical bug fixed**: dharma used `encode_buttons(("select",))` which raises
`ValueError: BitWorld input mask 16 is not in the trainable action set`.
Nirvana uses only valid buttons: up/down/left/right/a/b and their combos.

### File

`lessandro_nirvana_policy.py` — 1231-feature sprite_player parser + pixel fallback.
`lessandro_nirvana_bundle.zip` — ready to upload (4 KB).

### Strategy

1. **Voting phase**: press A every 45 ticks to vote
2. **Playing as crewmate**: navigate to nearest visible task bubble; follow task
   arrows when bubble is off-screen; spiral-explore when no tasks visible
3. **Playing as imposter** (kill ready): navigate to nearest non-self alive
   player; press A to kill when within 22px; fall back to crewmate strategy
4. **Playing as imposter** (cooldown): act as crewmate for cover
