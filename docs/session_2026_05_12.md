## Game: Among Them

Among Them is an Among-Us-style social deduction game running as a BitWorld
game engine (PICO-8 pixel rendering).

### Core specs (from mettagrid source)
| Parameter | Value |
|-----------|-------|
| Players | 8 |
| Imposters | 2 |
| Tasks per crewmate | 8 |
| Imposter kill cooldown | 1200 ticks |
| Vote timer | 600 ticks |
| Frame resolution | 128 × 128 pixels |
| Frame encoding | 4-bit packed (2 px/byte), PICO-8 16-color palette |
| Frame bytes per tick | 8192 |
| Default frame stack | 4 frames |
| Max ticks (default) | 10000 |

### Observation format (in Python policy)
```
raw_observations: np.ndarray  shape (batch, 4, 128, 128)  dtype uint8
                               values 0-15 (PICO-8 color index, ALREADY UNPACKED)
```

### Action space (27 total)
```
noop, a, b,
up, up+a, up+b,
down, down+a, down+b,
left, left+a, left+b,
right, right+a, right+b,
up+left, up+left+a, up+left+b,
up+right, up+right+a, up+right+b,
down+left, down+left+a, down+left+b,
down+right, down+right+a, down+right+b
```

### PICO-8 palette (index → color)
```
0=black        1=dark-blue     2=dark-purple  3=dark-green
4=brown        5=dark-gray     6=light-gray   7=white
8=red          9=orange        10=yellow      11=bright-green
12=blue        13=indigo       14=pink        15=peach
```

### 2. Anonymous token cannot upload
The token `6PnHPiX9SWLBZhkMyHr4JJWKuUWZY29t_2CTrVDICHs` authenticates as
`subject_type: anonymous` with `scopes: []` via:
```
GET https://api.observatory.softmax-research.net/whoami
→ {"subject_type":"anonymous","scopes":[]}
```
The upload endpoint (`POST /stats/policies/submit/presigned-url`) returns 401.

**Fix**: obtain a proper GitHub-authenticated token.
```bash
# On a machine with a browser:
softmax login          # opens browser → GitHub OAuth → saves token
softmax get-token      # print saved token
softmax set-token <token>   # set in headless env
```
The cogames CLI uses `X-Auth-Token: <token>` header (NOT `Authorization: Bearer`).

### 3. Docker validation requires PyPI internet access
The episode runner container (`ghcr.io/metta-ai/episode-runner:compat-v0.25`)
tries to pip install from PyPI inside Docker during policy loading. In this
sandbox environment, the container has no outbound network, so validation fails.

**Fix**: either pre-bake dependencies into the image or run validation from
an environment with internet access. The `--skip-validation` flag bypasses
the smoke test but still requires a working upload token.

## Policy: lessandro-dharma

### Strategy
Task-seeking via pixel color analysis on the most recent PICO-8 frame:

1. **Interact** (press A) when ≥15 task-indicator pixels are within ±12px of
   screen center (colors: orange=9, yellow=10, bright-green=11, pink=14, peach=15).
2. **Vote/report** (press SELECT) every 500 ticks to trigger meetings.
3. **Move toward** the quadrant (up/down/left/right) containing the most
   task-indicator pixels.
4. **A-press** every 30 ticks as a blind interaction attempt.
5. **Exploration spiral** when no task pixels visible:
   right, right, down, down, left, left, up, up (10-tick hold each).

### File
`lessandro_dharma_policy.py` — both `step_batch` (tournament) and per-agent
`step` paths implemented.

### Submission command (for when season exists and auth is valid)
